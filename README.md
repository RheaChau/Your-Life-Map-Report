# Your Life Map Report

Your Life Map Report is a privacy-first Codex skill for generating personalized BaZi and Ziwei reports. It translates traditional Chinese metaphysics into clear, practical insights on personality, relationships, work, health, life cycles, and timing.

## Install in Codex

Use the $skill-installer skill with this GitHub repository:

Repository: RheaChau/Your-Life-Map-Report
Path: .
Name: bazi-report-pdf-rheadesign

After installation, provide a JSON input containing the subject code, birth date and time, calendar type, gender, birthplace, current location, language, and calculation date. The skill calculates the chart and generates a structured PDF report. Birth details are used only for the requested calculation and should not be stored in the repository.

## Repository

The skill definition is in SKILL.md. Calculation code, report references, rendering scripts, and the starter input form are included in this repository.
