# 报告内容提纲

每节先放一段有出处的古籍原文节录，再进入现代汉语情境；不要把它们机械写成四个重复标签，用清楚的小标题和自然段把逻辑串起来：

1. **古籍原文**：第一段使用有出处的古籍短句或节录，标明书名；原文只做方法论引子，不把现代断语伪装成古文。
2. **盘面依据与现代解读**：第二段起只引用 `chart.txt` 中能核对的干支、十神、旺衰、宫位、四化、大运或流年信息，再说明它在成年人的做决定、带团队、处理钱、谈恋爱、照顾父母、恢复精力时可能怎样表现。术语首次出现要紧跟解释，例如“身宫（更像一个人把力气用到现实哪一块）”。
3. **可执行动作**：给 1–3 条低风险、可观察的行动；时间窗口明确到年份、月份或 90 天口径。
4. **整体边界**：只在报告前部集中说明流派差异、时刻误差和不可推断之处，章节正文不要每节重复置信度或“仅供参考”。

## 格局与身强身弱的深度判断

格局不是可供勾选的固定菜单。先看月令，再核对透干、根气、藏干、制化和刑冲合害，判断命局的主格、兼格、局部关系或不取此格。实际出现哪些结构就写哪些，未满足条件的格局要明确说明理由。可检查正格、变格、专旺/从格以及伤官配印、官印相生、杀印相生、食神制杀、财官印食、从财、从杀等组合。

格局段落固定回答四件事：

- 证据链：哪些天干地支、十神和组合让结构成立，哪些条件不足。
- 身强身弱：日主承载力怎样改变财、官杀、印、食伤的表现；说明喜忌如何随全局调整。
- 现实翻译：把结构落到工作权责、学习取证、钱与资源、亲密关系、家庭角色等具体场景。
- 大运触发：逐一写出每步十年运引动、补足或冲撞哪条链，可能出现的机会、摩擦、转折和应对方式。

每个格局专题第一段仍用有出处的古籍原文，第二段开始再翻译现代语境；不要把“某格必贵/必贫”当结论，也不要把一个十神的出现当成成格证明。

## 命主专属写作与去重

每份报告都必须从当前命主的 `chart.txt` 重新写作。标题、格局解释、十年大运、未来窗口、提运技巧和长期注意事项不得从其他命主报告复制；即使模块名称相同，也要改写为当前命局的性情、冲合、喜忌和现实场景。固定的古籍短引、免责声明和字段标签可以共用，正文的判断、比喻、建议和段落结构应体现当前命主的独特证据。生成后可用 `scripts/check_uniqueness.py` 与其他临时报告 JSON 做交叉核验，核验通过再清理敏感中间文件。

## 语言去 AI 化与篇幅

### 标题写法

每个模块的标题都使用总结型陈述句，承担对整节内容的归纳作用。标题直接说出盘面结论及其现实含义，例如“伤官格为主，专业判断要通过制度与边界转化为收入”“收入可以增长，但必须分清投入、资产与责任”。避免问句、冒号、栏目式提问和“你是什么样的人/适合什么”等泛化标题。

保留“日主、十神、格局、调候、命宫、身宫、四化、大运”等术语，但第一次出现就用一句白话解释。删掉空泛的“在当今时代”“值得注意的是”等开场，不堆叠“此外、同时、因此”，少用“不是……而是……”句式，不使用“人话解读”“赋能”“底层逻辑”等机器化词。每个模块写 2–5 个有信息量的段落，建议 2–4 条；标题要直接说明读者会得到什么，例如“你在工作中怎样发挥”“亲密关系里最容易卡在哪里”，不要使用“核心状态”“行动清单”这类看不出内容的空标题。开头与结尾集中说明参考性质，正文以清楚、具体、敢于落地的解读为主。全篇目标 8–10 页 A4，内容不足时不要用大留白凑页；内容需要时允许到 20 页。

健康只写作息、压力管理和体质倾向，不诊断疾病或给药；事业与财富只给能力/节奏/风险提示，不替用户做投资或离职决定；感情与父母关系避免贴标签和宿命断言。八字与紫微冲突时，分别呈现信号、说明权重依据，并保留低置信度结论。
