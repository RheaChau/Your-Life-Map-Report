# 多语言输出规则

- `language` 使用 BCP-47 风格标签，例如 `zh-CN`、`zh-TW`、`en-US`、`ja-JP`、`ko-KR`、`fr-FR`、`de-DE`、`es-ES`、`ar`、`hi`。
- 正文、标题、建议和免责声明使用目标语言；干支、十神、格局、调候、命宫、四化、大运等术语保留中文，并在首次出现时给出目标语言释义。
- 日期使用地区习惯格式，但 `forecast` 内部仍保留 ISO `YYYY-MM-DD`，避免跨语言歧义。
- 不做逐字机翻。短句、具体动词和生活场景优先；术语解释只保留理解所需的一句话。
- PDF 若缺少目标文字的字体、RTL 或复杂字形整形支持，应停止交付并说明缺失项；不要用方框字替代。
