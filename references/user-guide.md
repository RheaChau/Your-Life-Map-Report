# 使用方法（给报告使用者）

## 最短流程

1. 用浏览器打开 `templates/input-form.html`。它是离线表单，不会上传资料。
2. 填写代号、出生年月日时、阳历/阴历、闰月、性别、出生地、现居地、报告语言和截至日期，点击“下载 input.json”。代号建议使用 `A01` 这类代码，不填真实姓名。
3. 在 Codex 新消息中上传刚下载的 JSON，并把下面这一句一并发送：

   ```text
   使用 $bazi-report-pdf-rheadesign 读取我上传的 input.json，生成完整八字+紫微综合 PDF。按 input.json 的 as_of_date 实时计算未来 3 年和未来 3 个月；先依据月令、透干、根气、制化和组合关系判断这个命局实际成立的主格、兼格或局部结构（不要只在固定的几个格局中勾选），再结合身强身弱解释影响，并逐步落到每一轮十年大运可能出现的工作、财务、关系和生活现象；详细解释人格、优势盲点、健康精力、事业行业、财富、感情、父母家庭、社交合作、五行方位、完整十年大运、日常提运和长期注意事项；每个模块先放有出处的古籍原文节录，再用现代汉语解释；紫微术语首次出现时翻译；正文自然、去 AI 化，目标 8–10 页，内容需要时可到 20 页；输出前核对页数、文字和排版。
   ```

这就是完整要求，不需要再复制技能内部的 shell 命令。若不使用表单，也可以直接准备同结构的 `input.json` 后发送同一句话。

## 填写提醒

- 时间使用 24 小时制；不知道出生时辰时不要猜，先补充资料。
- 阴历必须勾选是否闰月。地点写城市或国家即可；技能不会擅自用经度做真太阳时校正。
- `as_of_date` 是本次报告的时间锚点。要更新趋势，只需改这个日期并重新上传 JSON。
- 想换语言时，同时设置 `language` 和 `locale`（例如 `en-US`、`ja-JP`）。阿拉伯文、印地文等文字需要系统有相应字体；若缺字体，先安装字体再渲染。

## 收到 PDF 后

检查 PDF 是否在合理篇幅内、中文/目标语言是否正常、出生信息是否正确、每个章节是否有具体解释和建议。确认无误后，只保留 PDF；删除 `chart.json`、`chart.txt`、`report.json` 等中间文件。PDF 会包含你选择展示的生辰字段，请自行保管，不要上传到公开仓库。

报告属于传统文化参考，不替代医疗、心理、投资、法律或其他专业意见。
